05 / PROJECT INFORMATION

SEARCHING FOR WORLDS

Exoplanet Habitability Prediction is a machine-learning based academic project designed to analyze astronomical parameters and classify whether an exoplanet falls within project-defined potential-habitability criteria.

The system combines Python, Flask, Pandas and Scikit-learn with a modern web interface to create an interactive prediction platform.
